# مدينتي الذكية (Smart City) - Flutter

المواطن يبلغ عن مشكلة في الشارع بصورة وموقع GPS ويتابع حالة البلاغ حتى الحل.

## التشغيل
1. ثبّت Flutter SDK (flutter.dev) وجهّز محاكي أندرويد أو موبايل بكابل.
2. افتح فولدر المشروع في الترمنال:
   flutter pub get
   flutter run
3. اسمح بإذن الموقع والكاميرا. على المحاكي حدد موقع من Extended controls > Location.
4. الخريطة محتاجة إنترنت (OpenStreetMap، بدون مفتاح API).

## الدخول
اكتب أي اسم واختار: مواطن (يعمل بلاغات ويتابعها) أو مسؤول (يشوف كل البلاغات ويغير الحالة).
الدخول محلي للعرض فقط، من غير باسورد.

## المتطلبات اللي اتنفذت
- Widgets و Screens: دخول، قائمة بلاغات بفلتر، بلاغ جديد، تفاصيل، خريطة.
- Provider: lib/providers/app_provider.dart
- قاعدة بيانات SQLite (sqflite) مع CRUD: lib/services/db_helper.dart
- Map: flutter_map + Marker لكل بلاغ، واختيار الموقع بالضغط على الخريطة.
- GPS: geolocator. الصورة: image_picker (كاميرا أو معرض).
- Timeline: كل تغيير حالة بيتسجل في جدول history بالخطوة والوقت والمنفذ، ويظهر في شاشة التفاصيل.
- Payment (بونص): شاشة دفع تجريبية بتحقق من البطاقة (Luhn وانتهاء وCVV)، بتتسجل في جدول payments وفي Timeline البلاغ. مفيش بوابة حقيقية ولا فلوس بتتخصم، ومحفوظ آخر 4 أرقام بس. بطاقة تجربة: 4242 4242 4242 4242.

## هيكل الكود
lib/models (Report, HistoryEntry) - lib/services (SQLite) - lib/providers - lib/screens

## لعرض المشروع (Demo)
1. ادخل كمواطن وأنشئ بلاغ بصورة وموقع.
2. شوفه في القائمة وعلى الخريطة.
3. اخرج وادخل كمسؤول، غيّر الحالة: قيد المراجعة ثم جاري الحل ثم تم الحل.
4. ارجع للتفاصيل واعرض الـ Timeline.
